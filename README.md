# Aplicación METAR Colombia

Aplicación web estática para consultar reportes METAR de aeropuertos en Colombia usando la API pública del Aviation Weather Center.

## Uso

1. Abre `index.html` en tu navegador.
2. Ingresa códigos ICAO (por ejemplo: `SKBO, SKRG`).
3. Presiona **Consultar** para ver los reportes METAR y TAF más recientes.
4. Usa **Actualizar WX Watch** para cargar la tabla oficial de alertas.

## Fuente de datos

- https://aviationweather.gov/api/data/metar
- https://aviationweather.gov/api/data/taf
- https://meteorologia.aerocivil.gov.co/wxwatch/table?list_id=4&ceiling_minimum=40000&visibility_minimum=170000
